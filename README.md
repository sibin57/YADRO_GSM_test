# YADRO_GSM_test
Репозиторий с решением тестового задания для YADRO Импульс, команда разработки подсистемы GSM-базовой станции

Для сборки при тестировании использовался компилятор gcc
после компиляции файл с csv-информацией передаётся напрямую в программу
ниже пример команды для компиляции и запуска
```bash
gcc main.c && ./a.out test.csv
```
